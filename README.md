# Body Fat Recommendation System - ANN Project

This is an Artificial Neural Network (ANN) based Body Fat Prediction System built using Python and Deep Learning techniques.

## Live Demo

Hugging Face App:

## Features

* Body fat prediction
* ANN model
* Feature scaling

* Streamlit interface

* Streamlit
